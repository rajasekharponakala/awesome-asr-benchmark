# Contributing

Thanks for helping keep this list useful.

## Adding an entry

1. Put it in the right section and table in `README.md`. Keep each table in chronological order, newest first.
2. Give the **year**, the **languages covered**, the **size** (hours, speakers or utterances), the **domain** and the **license**, where they are known.
3. Link the primary source: the paper (arXiv/ACL/ISCA), the dataset card, or the official repository. Avoid secondary news coverage.
4. Report numbers as the authors state them. Mark vendor-reported results as such.
5. If the entry is a notable 2025+ release, also add a row to **What's New**.

## Quality bar

- The resource must be publicly documented, with a paper, a dataset card or an official page.
- Benchmarks must state how the text is normalised, or link to the scoring code.
- No affiliate or tracking links.

## Pull requests

- One topic per pull request.
- Use a clear title, for example `Add <Benchmark name> (2026)`.
